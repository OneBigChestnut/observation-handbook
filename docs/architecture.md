# 观察手册：重构架构约定

## 产品边界

- 家庭由一个家庭管理员和若干只读成人组成；一个家庭始终只有一个管理员。
- 每位小朋友拥有独立的观察卡片、标签、观察手册与导出文件，所有查询与写入均以 `childId` 为边界。
- 一张观察卡片包含 1–4 张照片、一段文字与多个标签。
- 观察手册包含名称、内容介绍、开始/完成时间、封面照片与所属卡片；完成时间为空时表示持续观察。
- 家庭管理员可以直接将手册发布到公共空间；不存在审核队列。
- 家庭不能自定义模板，也没有自由页面编辑器。超级管理员维护版本化的固定模板；被使用的版本只能停用，不能删除或修改。

## 浏览与界面

- 卡片默认按月浏览，可切换到时间流和月历；今日记录以并列小卡片呈现，不提供手册入口。
- 小尺寸图片一律使用带尺寸的缩略图资源，不能直接加载原图。
- 主导航、公共空间和后台中心统一放在左侧；后台中心仅超级管理员可见。小朋友切换器固定在左侧底部。
- 视觉采用紧凑、正式、现代的档案出版物风格：低高度页眉、清晰的衬线标题与无衬线正文、柔和纸色和细边框。

## PDF 与模板

- 导出采用固定模板，支持屏幕 PDF 与印刷 PDF。
- 印刷 PDF 默认 3mm 出血与裁切线，并执行图片分辨率、安全区、文字溢出预检。
- 导出文件保存为不可变快照，包含所用模板版本与版面数据。

## 实施顺序

1. 领域规则与权限边界。
2. 家庭端响应式壳层、孩子切换与卡片浏览。
3. 卡片、标签、手册、发布与导出 API。
4. 超级管理员模板/成员/日志中心。
5. PDF 渲染与生产预检。
