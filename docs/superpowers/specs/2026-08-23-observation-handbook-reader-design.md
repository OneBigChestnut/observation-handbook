# 观察手册阅读与成册规格

## 目标

将观察手册统一为“封面模板 + 观察卡片序列 + 封底模板”的作品容器，并提供独立的整本阅读、排序、公开展示和 PDF 导出体验。

## 核心规则

1. 手册正文只能来自已经归入该手册的观察卡片，不存在脱离卡片的独立手册页面。
2. 封面和封底是手册级模板页面，由超级管理员配置；创建手册时选择模板并选择照片。
3. 封面自动展示手册名、制作人、所属家庭、制作时间和观察时间范围。
4. 封底自动展示手册名、记录者、观察时间范围、卡片数量、完成时间和可选总结信息。
5. 首次生成时，卡片按卡片 ID 升序排列；之后可在手册阅读器中调整顺序。
6. 封面和封底始终固定在首尾，不能被拖动到正文中间。
7. 观察手册列表只显示摘要；点击手册后打开独立阅读弹窗，不在列表下方内嵌展开。
8. 阅读弹窗左侧显示整本手册的页面缩略图，右侧显示当前页面的大图。
9. 卡片缩略图和大图必须使用卡片保存时的模板布局快照，不能重新套用会改变排版的模板。
10. 今日记录只负责缩略图和元信息；卡片编辑必须打开完整卡片编辑工作台。
11. 公开手册和公开示例沿用同一阅读器，但只能浏览，不能编辑、排序、删除或下载。
12. 删除或归档卡片时，必须同步处理其与手册的关系，不能留下失效卡片 ID。

## 页面与权限边界

- 新建观察手册：手册名称、介绍、时间、封面/封底模板、封面/封底照片。
- 今日记录：浏览卡片缩略图、标签、所属手册、制作日期、编辑、归档。
- 卡片编辑工作台：编辑卡片照片、文字、标签和手册归属。
- 手册阅读器：浏览页面、切换页面、调整卡片顺序（有权限时）。
- 模板管理：仅超级管理员配置封面、封底和卡片模板。
- 导出文件：按阅读器页面顺序生成包含封面、卡片和封底的 PDF。

## 模板与快照

模板内容包括固定的照片框、文字框和装饰线位置。卡片保存时记录模板布局快照；手册封面和封底保存所选模板版本及照片引用。模板后续更新不得改变已经保存的卡片或已生成手册。

## 空状态

刚创建但尚未收录卡片的手册可以只显示封面和封底，并明确提示“还没有收录观察卡片”。不得伪造正文页或用第一张卡片照片冒充封面。
