# 只读完整示例工作台设计

## 目标

公开示例必须复用登录后观察工作台的导航、卡片缩略图、模板预览、手册列表和成册预览，而不是维护一套独立展示页面。示例数据固定为只读演示家庭，与真实家庭账号隔离。

## 设计

- `AuthGate` 的公开入口创建一个标记为 `demo` 的演示工作区，并复用 `App`。
- `App` 根据演示标记选择本地演示加载器；真实账号继续使用 API 加载器。
- 演示加载器返回与 API 相同的 `ObservationCardSummary`、`HandbookSummary`、`TagSummary` 和 `ExportSummary` 结构，保证现有组件无需另写一套视图。
- 卡片点击打开现有 `CreateObservationCardForm` 的只读模式，显示绑定的模板、照片、文字、标签和手册，不显示保存、删除或上传操作。
- 今日记录、手册列表、手册收录卡片和成册预览均使用现有组件与样式。
- 演示账号没有任何写入 API 的能力；所有创建、修改、删除、下载控件隐藏或明确拒绝。

## 分阶段边界

本阶段只完成框架接入和少量可验证示例数据。300 张本地图片、5 个完整系列和批量素材管线在后续 Stage 2/3 实施。

## 验收

访客可从登录页进入原始工作台，看到今日记录；点击卡片进入原始卡片工作台只读查看；切换观察手册并查看收录卡片；进入导出文件看到成册记录但不能下载；退出后回到登录页。
